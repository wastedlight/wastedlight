## 👨‍💻 About Me

I'm a self-taught developer who enjoys building software, experimenting with new technologies and turning ideas into working projects.

My work covers bots, backend systems, APIs, game scripting, automation and application development. Most of my experience comes from building and maintaining my own projects, solving real problems and learning by doing.

- 🤖 Building bots, integrations and automation tools
- ⚙️ Developing backend systems, APIs and database-driven features
- 🎮 Working with Lua and game-server scripting
- 📱 Developing applications with Flutter
- 🧪 Always experimenting with something new

**Stack's a mess — and that's how I like it.**
